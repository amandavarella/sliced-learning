What this solves

The error overlay currently has no way to copy the full error details as
plain text. This adds a "Copy Error" button that copies the plugin name,
message, file location, code frame, and stack trace to the clipboard in
one click.

Fixes #22980

Alternatives explored

Manual text selection works but is unreliable across the overlay's
scrollable stack trace section, and requires multiple separate selections
to capture everything (plugin, message, file, frame, stack).

Attention needed
